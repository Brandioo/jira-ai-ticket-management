# Jira AI Ticket Management — Frontend

React 19 + TypeScript + Vite frontend for the Jira-style education project.

## Start

```bash
cp .env.example .env
npm install
npm run build
npm run dev
```

Frontend URL:

```text
http://localhost:5173
```

The `.env.example` already points to:

```text
VITE_API_URL=https://jira-ai-ticket-management-backend.ddev.site/api
```
